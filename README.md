# 🌦️ Weather Application

A sleek and responsive weather forecast app built with **React**, **Vite**, and **JSX**.  
It fetches real-time weather data using the **OpenWeatherMap API** and displays it in a simple UI.

> ✅ Hosted on GitHub Pages:  
> 🔗 [Live Demo](https://vigneshwaran2406.github.io/weather-application/)

---

## 📌 Features

- 🌐 Get current weather data by city name
- 📍 Supports temperature, weather condition, humidity, wind speed
- 🌙 Responsive UI with clean design
- ⚡ Built using fast Vite bundler
- 🌍 Powered by OpenWeatherMap API

---

## 🛠️ Tech Stack

- **React**
- **Vite**
- **JSX**
- **CSS**
- **OpenWeatherMap API**
- **GitHub Pages** for hosting

---

## 🚀 Setup & Installation

```bash
# Clone the repo
git clone https://github.com/Vigneshwaran2406/weather-application.git

# Navigate into the directory
cd weather-application

# Install dependencies
npm install

# Start the development server
npm run dev
